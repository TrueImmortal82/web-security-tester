**Aurora Secure (AuditPro Master)** — автономный программный комплекс для автоматизированного аудита безопасности, глубокой проверки верстки (UI/UX QA) и оценки зрелости веб-приложений и корпоративных интранет-порталов.

Поставляется в виде готового **портативного исполняемого файла (.exe)** для Windows. Установка Python и сторонних библиотек не требуется.

## 🚀 Быстрый старт

1. Перейдите в [**Releases**](https://github.com/TrueImmortal82/web-security-tester/releases/latest) и скачайте `AuditProMaster.exe` (или zip-архив).
2. Запустите `AuditProMaster.exe` на Windows 10/11.
3. В открывшемся графическом окне введите URL целевого портала (например, `https://target.internal/`).
4. Нажмите кнопку **«ЗАПУСТИТЬ СКАН»**.
5. **Авторизация (при необходимости):**
   - Откроется окно браузера Chrome.
   - Выполните вход под своей учетной записью в веб-сервисе.
   - В окне программы нажмите **«ПРОДОЛЖИТЬ ПОСЛЕ ВХОДА»** (Proceed after login).
6. Программа выполнит обход маршрутов, проверку безопасности, UI-инспекцию и автоматически сформирует интерактивный HTML-отчет в браузере.

## 🛡 Возможности сканера

### 1. Безопасность и инфраструктура
- **Anti-False-Positive Baseline:** Распознавание одностраничных приложений (SPA catch-all) для исключения ложных срабатываний.
- **Поиск скрытых и чувствительных файлов:** Детекция открытых `.env`, `.git`, `Dockerfile`, конфигурационных файлов, резервных копий и дампов БД.
- **Анализ заголовков безопасности:** Проверка конфигураций CSP, HSTS, X-Frame-Options, X-Content-Type-Options, Referrer-Policy.
- **Идентификация стека:** Распознавание версий используемых библиотек (jQuery, Bootstrap и др.) и проверка известных уязвимостей.
- **SSL/TLS аудит:** Анализ защищенности транспортного уровня и сертификатов.

### 2. Frontend QA и UI/UX инспекция
- **Дефекты разметки:** Обнаружение горизонтальной прокрутки, перекрытия элементов, обрезанного текста, пустых заголовков.
- **Интерактивные элементы и доступность (a11y):** Поиск полей ввода без меток, кнопок без описания, изображений без alt-текста, некликабельных мелких зон.
- **Runtime-мониторинг:** Перехват ошибок JavaScript в консоли браузера и выявление медленно загружающихся ресурсов.
- **Скриншоты страниц:** Автоматическое сохранение скриншотов ключевых состояний страниц.

### 3. Чистота кода и артефакты
- Выявление отладочных инструкций (`debugger`, `console.log`).
- Поиск оставленных комментариев `TODO`, `FIXME`, `HACK`.
- Обнаружение тестовых мок-данных и заполнителей контента.

### 4. Интерактивная отчетность
- Расчет метрики **Trust Score v2**.
- Градация уязвимостей по уровням критичности (`Critical`, `High`, `Medium`, `Low`, `Info`).
- Стратегическая дорожная карта устранения выявленных дефектов.
